# opencode-sandbox

Project TypeScript nho, dung lam **workspace thu nghiem duy nhat** cua OpenCode
Telegram Remote Gateway o Milestone 0.

Vi sao phai la project TypeScript that chu khong phai README suong: phep do RAM
duoi tai (Milestone 0 buoc 5) va cau hoi "permission.lsp = deny co ngan duoc
language server khoi dong khong" deu can `typescript-language-server` chay that.
Sandbox khong co file `.ts` thi no khong bao gio khoi dong, va so do se xanh gia
-> ngan sach RAM chot sai -> OOM khi gap tai that.

Repo nay co y de PUBLIC de khong phai cap credential clone tren vpn4.
